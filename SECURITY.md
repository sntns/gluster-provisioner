# Security Policy

## Supported versions

Only the latest `main` branch and the latest released container image tags are supported.

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Instead:

- Contact the maintainers privately (preferred): `contact@sentiens.fr`, or
- If private contact isn’t available yet, open a minimal issue without exploit details and request a private channel.

Include:

- A clear description of the issue
- Steps to reproduce
- Affected versions / image tags
- Any suggested mitigation

## Coordinated disclosure

We aim to acknowledge reports quickly and coordinate a fix and release before public disclosure when feasible.
